### Test cases (Given/When/Then)
**TC-048-01 inventory one-to-one (AC-D-013-08).** Given the frozen keys, when record headings are enumerated in each namespace SKILL.md and references, then all 29 keys have exactly one record each and no extra or duplicate record exists.
**TC-048-02 record completeness sample (AC-D-013-02..05).** Given connection.create, connection.update_secrets, connection.upload_custom_jdbc_drivers, file_import.execute, table_import.list, virtual_table.create, record.search, check.create, check.replace and check_report.get_latest, when each is read, then resource, effect and side effect, input meaning, result and failure interpretation and a coherent example are correct against the installed CLI.
**TC-048-03 offline copied-folder representative run (AC-D-013-06,07).** Given the copied folders with no network, when a novice agent follows one example in each of the three namespaces with mock or recorded output, then it chooses valid inputs, interprets the result and next operation, and every required local link resolves.
**TC-048-04 install prerequisite (BR-012-09).** Given the three SKILL.md files, when the install blocks are read, then each names pal_found_cli and gives conda `-c t-jet`, pip and uv commands.
**TC-048-05 300-line leaf limit (SA-DES-012).** Given every markdown part of all three folders, when line counts are checked, then each part is at most 300 lines.
**TC-048-06 connectivity pagination and bounded upload (AC-D-013-04,09).** Given file_import.list and table_import.list cursor pagination and connection.upload_custom_jdbc_drivers, when the records are read, then the page-token follow-up and the bounded driver upload size limit are stated, and a short page is not read as end of data.
**TC-048-07 data-health and checkpoints write and read semantics (AC-D-013-03,05,09).** Given check.replace, check.create, check_report.get_latest and record.search, when the records are read, then the replace-class write semantics, the metadata-only limits, the latest-report meaning and the record-search pagination are stated.
**TC-048-NEG-01 missing or duplicate record.** Given a key with no heading or two headings, when the inventory check runs, then it fails naming the key.
**TC-048-NEG-02 unsupported call.** Given an operation not in the register, when the skill is read, then it is not presented as callable.
**TC-048-NEG-03 stale example.** Given an example selecting a different resource.operation than its heading, when parsed, then it fails.
**TC-048-NEG-04 unresolved link.** Given a relative link that escapes the folder or targets a missing file, when resolved, then it fails.

29/29 keys with exactly one record; zero duplicates or extras; completeness sample passes; zero unresolved local links; install blocks present in all three; every part at most 300 lines; pagination, bounded upload and metadata-only semantics documented.
