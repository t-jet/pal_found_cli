### Key Review Concerns Identified from Documentation Study:
1. **Jitter implementation precision**: ADR-002 specifies ±10% jitter but ADR-004 doesn't detail the math. Verify: delay * (1 + random.uniform(-0.1, 0.1)) or equivalent.
2. **Error envelope JSON priority**: SRS-001 FR-ERR-4 states ALL errors use JSON on stdout. Verify OutputFormatter doesn't accidentally TOON-ize error data.
3. **Metadata separator placement**: ADR-005 requires # ---metadata-start--- before metadata JSON. Verify LogSetup and PaginationHelper coordinate correctly.
4. **TOON uniformity edge cases**: ADR-004 step 7 requires strict key-set equality. Verify empty dict handling and None value handling.
5. **RetryHandler timeout interaction**: asyncio.wait_for raises CancelledError — verify ErrorSerializer handles this as exit code 5.
6. **Exit code 7 (RateLimitExhausted)**: Must be set only when max retries exhausted, NOT on first 429. Verify RetryHandler state machine.
7. **LogSetup stderr isolation**: Verify NDJSON logs don't corrupt stdout or metadata output.
