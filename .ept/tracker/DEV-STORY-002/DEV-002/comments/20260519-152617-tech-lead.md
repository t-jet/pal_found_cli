### Implementation Details

**AC1: RetryHandler** (`retry.py`)
- Configurable: max_retries, base_delay, max_delay, jitter
- Exponential backoff: `delay = min(base_delay * (2 ^ attempt), max_delay)`
- Environment variables: FOUNDRY_MAX_RETRIES (3), FOUNDRY_RETRY_BASE_DELAY (1.0), FOUNDRY_RETRY_MAX_DELAY (30.0), FOUNDRY_RETRY_JITTER (true)
- Decorator (`@RetryHandler()`) and context manager (`async with handler.context()`) protocols
- Configurable exception types (default: requests.RequestException)
- NDJSON logging to stderr (ADR-005)

**AC2: ErrorSerializer** (`error_serializer.py`)
- Maps exceptions to ADR-001 exit codes (1-9):
  - 1: UserInputError (ValueError, TypeError)
  - 2: AuthenticationError (HTTP 401)
  - 3: PermissionDeniedError (PermissionError, HTTP 403)
  - 4: NotFoundError (FileNotFoundError, HTTP 404)
  - 5: TimeoutError (TimeoutError)
  - 6: ServerError (HTTP 5xx excl. 503)
  - 7: RateLimitExhausted (HTTP 429)
  - 8: AccessControlError
  - 9: ConfigurationError (ImportError, OSError)
- HTTP status code classification from response objects
- MRO-based exception type matching
- JSON error envelope with all required fields

**AC3: OutputFormatter** (`output_formatter.py`)
- 7-step ADR-004 auto-selection algorithm implemented
- JSON and TOON (tabular) output formats
- Pretty-print support for JSON
- Error envelopes always JSON
- Pagination metadata to stderr

**AC4: LogSetup** (`log_setup.py`)
- Pre-existing implementation — no changes needed
- NDJSON structured logging to stderr (ADR-005)
- Metadata separator support
