## Concrete technical plan

**Summary:** Public GitHub visibility and anonymous access verification for three repositories.

**Components:** Repository settings checklist; visibility/branch-protection configuration; anonymous clone/API/release probes; secret-scope review.

**Interfaces:** Inputs: final public repository URLs and GitHub owner permissions. Outputs: public repositories, verification log, retained protections.

**Integration:** DEV-STORY-024 split order; DEV-STORY-026/028 publication workflows; DEV-STORY-033 skills clone URL.

**Risks:** Insufficient owner permission, leaked internal content, secret scope drift. Mitigate with preflight scan, least-privilege settings, and per-repo verification.

**Acceptance criteria:**
- Given final repositories, when visibility is set, then unauthenticated users can browse and clone all three. Given tags/releases, when a visitor downloads assets, then access works without login. Given repository secrets, when reviewed, then no cross-repo secret is exposed.

**Test strategy:** Anonymous clone, metadata/browse, tags/releases/assets, issue/PR visibility, branch-protection and secret-scope checks.

**Estimate:** 5 story points; DESIGN 5h, DEV 12h, UNITTEST 8h, CODEREVIEW 4h, TESTCASE 6h, TESTEXEC 6h, DEVOPS 8h.
