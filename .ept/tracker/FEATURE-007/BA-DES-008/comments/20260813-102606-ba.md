## Business design plan - BA-DES-008 (author ba)

### Business case
Skills are distributed as files, not as an installable package. Cloning the pal_found_cli_skills repository (repo name per ND-010-01) and copying the pal-found-* skill folders into the target harness is a simple, dependency-free distribution method. Clear instructions make it reliable for every harness and easy to update by re-cloning.

### Acceptance criteria (scope for design)
- Given a user, when they clone the pal_found_cli_skills repository, then they receive all skill content.
- Given a cloned repository, when the user follows the copy instructions, then the skills become available in the target harness.
- Given a skills repository update, when a user pulls or re-clones, then they can refresh local skills to the latest version.
- Given a user on any supported harness, when they follow the instructions, then the steps are clear and complete.
- Given the repository documentation, when a user reads it, then cloning, copying, and updating steps are described.
