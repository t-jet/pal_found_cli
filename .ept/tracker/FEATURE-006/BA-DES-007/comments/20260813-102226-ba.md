## Business design plan - BA-DES-007 (author ba)

### Business case
Skills currently live in a Claude-specific layout (.claude/skills) that other harnesses do not use. Moving all skills to the standard .agents/skills folder (skill folders renamed pal-found-* per ND-010-04) gives every harness one canonical discovery location, removes duplicated copies and makes maintenance consistent.

### Acceptance criteria (scope for design)
- Given a supported agent harness, when it loads skills from .agents/skills, then it discovers all pal-found-* skills.
- Given a skill author, when they add or update a skill, then they store it once in .agents/skills and all harnesses use that content.
- Given the old Claude-specific layout, when migration completes, then no skill content exists only in the old location.
- Given a harness that does not support the standard folder, when it is onboarded, then clear instructions exist for pointing it at the skills.
- Given all skill folders, when naming is checked, then each uses the pal-found-* prefix.
