# Analysis plan + DoD compliance evidence - Open to In Progress - BA-ANA-006

Transition target: In Progress. Responsible role: ba. Date: 2026-08-12.

## Business case
Storing all skills in a standard .agents/skills folder makes the skills usable by every agent harness (Claude, Copilot, and others) instead of only Claude-specific layouts. One canonical location reduces maintenance and duplication.

## Analysis plan
1. Study source requirements (Project Owner architecture-change request 2026-08-11; parent FEATURE-006).
2. Derive finite set of business requirements in business terms.
3. Prepare acceptance criteria in Given/When/Then format.
4. Analyze impact to end-to-end business processes (harness onboarding, skill discovery, maintenance).
5. Define access restriction changes (folder access and discovery per harness).
6. Document assumptions and risks.
7. Evaluate request rate and data size changes.
8. Produce business analysis deliverable and update document_index.md.

## Acceptance criteria (prepared)
- AC1: Given a supported agent harness, When it loads skills from the standard location, Then it discovers all foundry skills.
- AC2: Given a skill author, When they add or update a skill, Then they store it once in .agents/skills and all harnesses see the same content.
- AC3: Given an existing Claude-specific skill layout, When migration completes, Then no skill content lives only in the old location.
- AC4: Given a harness that does not support the standard folder, When it is onboarded, Then clear instructions exist for pointing it at the skills.
