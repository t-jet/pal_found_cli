# Requirements and analysis results - BA-ANA-006

Date: 2026-08-12. Author: ba.

## Business requirements (finite set)
- BR-006-01: All agent skills stored in the standard .agents/skills folder.
- BR-006-02: Every supported harness can discover and load the skills from that folder.
- BR-006-03: Skill content stored once; no per-harness duplicates.
- BR-006-04: After migration, no skill content lives only in the old location.
- BR-006-05: Harnesses not recognizing the folder get clear onboarding instructions.

## Impact on end-to-end business processes
- Harness onboarding: one standard location.
- Skill maintenance: one copy to update.
- Distribution: standard layout simplifies git-based distribution.
- Upgrades: updates propagate to all harnesses at once.

## Access restriction changes
- No new restrictions; folder is part of the skills repository.

## Assumptions and risks
- Assumption: standard layout accepted by target harnesses.
- Risk: a harness silently ignores the folder; mitigated by discovery verification and instructions.
- Risk: old and new locations drift; mitigated by removing the old location after migration.

## Request rate and data size changes
- Request rate: none; skill loading is local.
- Data size: small markdown files; unchanged by the move.
