### Timeout

Resolve one effective per-attempt timeout before client invocation. Pass that same value to SDK request_timeout and RetryHandler wait_for; CLI --timeout wins over configuration in both layers. CLI value must be integer seconds 1..3600 inclusive; malformed, fractional, zero, negative or above3600 CLI input is user error, exit1 with JSON stdout and no SDK invocation. CLI must use an explicit None check, so zero cannot silently select default.

Without CLI override, ordinary namespaces use FOUNDRY_AGENTIC_CLI_TIMEOUT_S/default30. Streams uses its separate FOUNDRY_AGENTIC_CLI_STREAMS_TIMEOUT_S/default120 as current namespace contract; global30 does not replace separate120. Normalize environment integer values by clamping to1..3600; missing or malformed/nonfinite/fractional values fall back to relevant30/120 default. This invalid-env policy is a new implementation clarification preserving existing ConfigLoader normalization, not a quoted business requirement. Shared helper/direct RetryHandler default path must enforce same bounds, avoiding independent unclamped float parsing. Explicit constructor timeout None may remain an internal test-only bypass; CLI must never select it. Explicit numeric helper/constructor overrides must be finite and within1..3600; subsecond finite values may remain for bounded internal tests, never CLI/env configuration. Each retry gets its own timeout; total command duration may include multiple attempts and backoff. Preserve ADR001 terminal-error mapping and cancellation behavior.

### Attempts

FOUNDRY_AGENTIC_CLI_RETRY_MAX_ATTEMPTS means total calls including first. Default4; value1 means first call with no retry; value3 means at most3 calls and2 delays. Parse integer env; malformed/fractional/nonfinite falls back4, nonpositive integer normalizes1. No undocumented upper cap. This normalization is an explicit implementation clarification. Canonical new max_attempts constructor accepts positive integer, rejects bool/noninteger/nonpositive. For explicit legacy max_retries=N preserve N retries plus first call (N+1 total), including0 giving1 total; reject negative/noninteger/bool. Reject simultaneous non-None max_attempts and max_retries. Default constructor must use canonical env total count, never legacy off-by-one. Preserve existing retryability taxonomy and immediate success/nonretryable exit.
