Business requirements defined in this design (BD-012-01..06), all traceable to the deliverable .ept/docs/deliverables/business_design/BA-DES-012-doc-only-skills.md and to BA-ANA-012 BR-011-01..07:

- BD-012-01: Each of the 18 namespace skills is documentation only (a single SKILL.md, no Python script). -> AC-D-012-01
- BD-012-02: Every SKILL.md invokes the matching pal-found-* command; no python ..._cli.py example remains. -> AC-D-012-02
- BD-012-03: All command behavior comes from the installed tool, never from code stored in the skills repo. -> AC-D-012-07
- BD-012-04: A skill user needs no Python knowledge; the command name suffices. -> AC-D-012-03
- BD-012-05: Datasets and ontologies retain their operation set via pal-found-datasets / pal-found-ontologies after the skill copies are removed. -> AC-D-012-04, AC-D-012-05
- BD-012-06: Distribution and onboarding docs describe skills as documentation-only and state the tool install prerequisite. -> AC-D-012-06, AC-D-012-08

Acceptance criteria written in Given/When/Then (BDD) in section 9 of the deliverable. Traceability matrix in section 13 links business requirements -> dev stories -> acceptance criteria.
