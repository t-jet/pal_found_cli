Architecture approach documented (full detail in deliverable .ept/docs/deliverables/architecture/SA-ANA-012-doc-only-skills-architecture-analysis.md):

APPROACH: Doc-only skill model. Each of the 18 namespace skills becomes a single SKILL.md that documents purpose + operations and invokes the installed pal-found-* command by name. Tool (pal_found_cli_tool) is the single source of command behavior. Constraints: canonical naming (18 pal-found-* entry points match 18 skill folders per ND-010-03), no behavior duplication, no Python knowledge required, tool install is the dependency.

RETIRE LAUNCHER LAYER: 16 thin launchers proxy to packaged modules with no added behavior; removing them changes nothing at command level. Datasets/ontologies carry full copies (not thin wrappers).

DATASETS/ONTOLOGIES MIGRATION: Tool owns verified supersets -- pal-found-datasets 33 ops / 732 lines, pal-found-ontologies 67 ops / 1225 lines; skill copies 526 and 503 lines. Remove stale skill copies; verify tool covers operations; no new tool command required.

RISKS: tool-install prerequisite, stale invocation text, datasets/ontologies drift, docs/structure misalignment, downstream EPIC-009/010 designs. Dependencies: EPIC-011 created at design start (BR-011-07); tool distribution chain on EPIC-010.

Cross-checked with BA-ANA-012 deliverable; BA's superset finding confirmed at architecture level.
