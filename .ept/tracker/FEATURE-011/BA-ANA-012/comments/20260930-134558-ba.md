Business requirements (BA-ANA-012, FEATURE-011):
BR-011-01: every namespace skill under .agents/skills/pal-found-* MUST contain no separate Python script.
BR-011-02: each skill MUST be a single SKILL.md documenting purpose and covered operations.
BR-011-03: each SKILL.md MUST invoke installed pal-found-* commands, never python ..._cli.py.
BR-011-04: any command implementation MUST live in the tool (pal_found_cli_tool) and be exposed via its console commands.
BR-011-05: using a skill MUST NOT require Python knowledge.
BR-011-06: datasets/ontologies behavior MUST be preserved by the tool's own implementations when skill copies are removed.
BR-011-07: a new Epic MUST group the doc-only implementation (created at design start).
Full detail, impact, acceptance criteria (AC-011-01..07), assumptions/risks in deliverable .ept/docs/deliverables/business_analysis/BA-ANA-012-doc-only-skills.md.
