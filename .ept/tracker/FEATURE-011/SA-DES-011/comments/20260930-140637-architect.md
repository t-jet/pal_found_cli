Architecture approach (doc-only skill model):
- Repository-level and interface changes: skills repo sweeps all 18 namespace skill folders to a single doc-only SKILL.md that invokes the installed pal-found-<ns> command; no folder retains a scripts/ directory. Tool repo (pal_found_cli_tool) is unchanged: pyproject.toml [project.scripts] keeps the 18 pal-found-* entry points; datasets 33 ops / ontologies 67 ops are verified supersets, so NO net-new tool command (AC-1, AC-3).
- Launcher-layer retirement (UC-2): the 16 thin launchers (10-26 lines) proxy to the packaged module and add no behavior. Removal changes nothing at the command level because the packaged entry points stay installed; each SKILL.md usage text references pal-found-<ns> instead of a python ..._cli.py path (AC-2).
- Datasets/ontologies migration (UC-3): remove the stale standalone scripts/ copies (pal_found_datasets_cli.py, pal_found_ontologies_cli.py) and rewrite the two SKILL.md files to invoke the tool commands. Operation parity verified 33/67 (parity procedure in section 4.1) (AC-3).
- Non-functional requirements (section 5): MNT-1, USE-1, COM-1, CNS-1, DIS-1, SEC-1, PRF-1, VER-1, VER-2 (AC-4).
- Infrastructure and packaging (section 6): delete scripts/ in skills repo; no tool packaging change; onboarding states the tool-install prerequisite; CI/markdown gate rejects python ..._cli.py text and scripts/ directories; document_index updated (AC-5).
- Step-by-step migration procedure (section 7): Phase 1 docs sweep, Phase 2 remove scripts/, Phase 3 verify datasets/ontologies parity, Phase 4 verify distribution, Phase 5 register; rollback = restore from prior release tag, no tool-side rollback needed (AC-6).
- Risks (section 8): tool-install-missing, stale invocation text, datasets/ontologies drift, downstream docs, design/story misalignment; all mitigated (AC-7).
- API endpoints: no functional API change; all 18 pal-found-* installed commands unchanged. All API endpoints/interfaces identified with required changes (none required beyond SKILL.md text and scripts/ removal).
