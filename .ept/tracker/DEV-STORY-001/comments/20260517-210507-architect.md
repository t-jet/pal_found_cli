## Technical Scope & Constraints

### Technical Components

1. **ConfigLoader** — Configuration loading subsystem
   - Loads .env via python-dotenv (load_dotenv override=False)
   - Implements ADR-006 search path: FOUNDRY_AGENTIC_CLI_ENV_FILE → git root .env → CWD → env vars only
   - Git root detection via pathlib ancestor walk (max 20 levels)
   - Exposes typed getters: get_str(), get_bool(), get_int(), get_float(), get_enum()
   - Covers all 20+ global env vars from canonical-env-var-reference.md

2. **AuthProvider** — Authentication provider
   - Resolves FOUNDRY_TOKEN and FOUNDRY_HOSTNAME from ConfigLoader
   - Constructs UserTokenAuth from foundry-auth library
   - Validates credential presence before returning
   - Security: never logs or writes credentials to stdout

3. **AsyncClientFactory** — Client factory
   - Creates AsyncFoundryClient per invocation (stateless)
   - Injects attribution headers when FOUNDRY_AGENTIC_CLI_ENABLE_ATTRIBUTION=true
   - Accepts ConfigLoader and AuthProvider as dependencies

### Dependencies

| Component | Depends On | External Library |
|---|---|---|
| ConfigLoader | python-dotenv | python-dotenv |
| AuthProvider | ConfigLoader | foundry-auth |
| AsyncClientFactory | AuthProvider, ConfigLoader | foundry-platform-python, foundry-auth |

### Constraints

- Must be compatible with foundry-platform-python SDK (version TBD)
- Must be copyable to each namespace skill directory (single-file distribution)
- Zero runtime dependencies beyond SDK and toon library
- Python 3.11+ type hints
- No credentials logged or written to stdout
- Exit codes per ADR-001: 2 (AuthenticationError), 9 (ConfigurationError)

### Error Handling

- ConfigurationError (exit 9): Missing required env var, malformed config, explicit env file not found
- AuthenticationError (exit 2): Invalid or expired FOUNDRY_TOKEN

### Invocation Chain (from SAD-001 §6.1)

`
ConfigLoader.load() → AuthProvider.validate() → AsyncClientFactory.create() → ...
`

### Blockers

None identified. All architecture decisions documented in ADR-001, ADR-006, and SAD-001.
