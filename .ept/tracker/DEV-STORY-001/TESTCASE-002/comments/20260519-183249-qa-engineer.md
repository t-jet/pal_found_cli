### Suite 1: ConfigLoader Integration Tests (TC-CL-INT-001 through TC-CL-INT-011)

#### TC-CL-INT-001: Explicit .env path (FOUNDRY_AGENTIC_CLI_ENV_FILE) loads successfully
- **Given:** A temporary `.env` file exists with `FOUNDRY_TOKEN=test123`
- **And:** `FOUNDRY_AGENTIC_CLI_ENV_FILE` env var is set to that file path
- **When:** `ConfigLoader().load()` is called
- **Then:** `cfg.token` returns `"test123"`
- **And:** `cfg.loaded_file` equals the explicit path

#### TC-CL-INT-002: Explicit .env path that does not exist raises ConfigurationError
- **Given:** `FOUNDRY_AGENTIC_CLI_ENV_FILE` is set to a non-existent path
- **When:** `ConfigLoader().load()` is called
- **Then:** `ConfigurationError` is raised; exit code 9

#### TC-CL-INT-003: Git root `.env` discovered and loaded (Order 2)
- **Given:** A temporary git repo (`.git` marker) with `.env` containing `FOUNDRY_TOKEN=gitroot_token`
- **And:** CWD is set to a subdirectory within that repo
- **When:** `ConfigLoader().load()` is called
- **Then:** `cfg.token` returns `"gitroot_token"`

#### TC-CL-INT-004: CWD `.env` fallback when no git root
- **Given:** A temporary directory without `.git` containing `.env` with `FOUNDRY_TOKEN=cwd_token`
- **When:** `ConfigLoader().load()` is called
- **Then:** `cfg.token` returns `"cwd_token"`

#### TC-CL-INT-005: Env vars only — no .env file, no error (Order 3)
- **Given:** A directory with no `.env` and no `.git`; `FOUNDRY_TOKEN=shell_token` in shell
- **When:** `ConfigLoader().load()` is called
- **Then:** No exception; `cfg.token` returns `"shell_token"`; `cfg.loaded_file` is `None`

#### TC-CL-INT-006: Shell env var takes precedence over `.env` value (override=False)
- **Given:** `.env` with `FOUNDRY_TOKEN=envfile_token`; shell has `FOUNDRY_TOKEN=shell_token`
- **When:** `ConfigLoader().load()` is called
- **Then:** `cfg.token` returns `"shell_token"` (shell wins)

#### TC-CL-INT-007: Git root walk respects max_depth=20 limit
- **Given:** A directory structure deeper than 20 levels without `.git`
- **When:** `ConfigLoader()._find_git_root(max_depth=20)` is called
- **Then:** `None` is returned (no infinite loop)

#### TC-CL-INT-008: ConfigLoader typed property accessors return correct types
- **Given:** Env vars: `READONLY=true`, `TIMEOUT_S=60`, `ENABLE_ATTRIBUTION=1`, `LOG_LEVEL=DEBUG`
- **When:** Properties accessed
- **Then:** `global_readonly` returns `True` (bool), `timeout_s` returns `60` (int), `enable_attribution` returns `True` (bool), `log_level` returns `"DEBUG"` (string)

#### TC-CL-INT-009: Timeout clamping to min/max bounds
- **Given:** `TIMEOUT_S=0` returns `1`; `TIMEOUT_S=9999` returns `3600`

#### TC-CL-INT-010: Timeout returns default on invalid value
- **Given:** `TIMEOUT_S=not_a_number` returns `30` (DEFAULT_TIMEOUT_S)

#### TC-CL-INT-011: Boolean property parsing accepts true/1/yes variants
- **Given:** `READONLY` set to each of: `"true"`, `"1"`, `"yes"` all return `True`; `"false"`, `"0"`, `"no"` all return `False`

### Suite 2: AuthProvider Integration Tests (TC-AP-INT-001 through TC-AP-INT-006)

#### TC-AP-INT-001: validate() returns (True, None) with both token and hostname
- **Given:** `token="test_token"`, `hostname="foundry.example.com"`
- **When:** `AuthProvider.validate(token, hostname)`
- **Then:** Returns `(True, None)`

#### TC-AP-INT-002: validate() rejects missing token (None)
- **Given:** `token=None`
- **Then:** Returns `(False, "Missing FOUNDRY_TOKEN credential")`

#### TC-AP-INT-003: validate() rejects missing hostname (None)
- **Given:** `hostname=None`
- **Then:** Returns `(False, "Missing FOUNDRY_HOSTNAME credential")`

#### TC-AP-INT-004: validate() rejects empty string token
- **Given:** `token=""`
- **Then:** Returns `(False, "Missing FOUNDRY_TOKEN credential")`

#### TC-AP-INT-005: get_auth() constructs UserTokenAuth from valid credentials
- **Given:** Mocked `foundry_sdk.UserTokenAuth`
- **When:** `AuthProvider.get_auth("token", "host")`
- **Then:** `UserTokenAuth` instantiated with `"token"`

#### TC-AP-INT-006: get_auth() raises ConfigurationError when SDK not installed
- **Given:** `foundry_sdk` import raises `ImportError`
- **When:** `AuthProvider.get_auth("t", "h")`
- **Then:** `ConfigurationError` raised with message about SDK not installed

### Suite 3: AsyncClientFactory Integration Tests (TC-ACF-INT-001 through TC-ACF-INT-007)

#### TC-ACF-INT-001: create() succeeds with valid credentials
- **Given:** Mocked SDK, ConfigLoader with `token="test"`, `hostname="host"`
- **When:** `AsyncClientFactory.create(cfg)`
- **Then:** `FoundryClient` instantiated with auth and hostname

#### TC-ACF-INT-002: create() raises ConfigurationError when token missing
- **Given:** ConfigLoader with `token=None`
- **When:** `AsyncClientFactory.create(cfg)`
- **Then:** `ConfigurationError` raised

#### TC-ACF-INT-003: create() raises ConfigurationError when hostname missing
- **Given:** ConfigLoader with `hostname=None`
- **When:** `AsyncClientFactory.create(cfg)`
- **Then:** `ConfigurationError` raised

#### TC-ACF-INT-004: Attribution headers injected when ENABLE_ATTRIBUTION=true + RIDs set
- **Given:** Config with `enable_attribution=True`, `attribution_rids="rid-1,rid-2"`
- **When:** `AsyncClientFactory.create(cfg)`
- **Then:** `FoundryClient` kwargs contain `attribution_rids=["rid-1", "rid-2"]`

#### TC-ACF-INT-005: No attribution headers when ENABLE_ATTRIBUTION=false
- **Given:** Config with `enable_attribution=False`
- **When:** `AsyncClientFactory.create(cfg)`
- **Then:** `FoundryClient` kwargs do NOT contain `attribution_rids`

#### TC-ACF-INT-006: get() returns cached instance after create()
- **Given:** `create()` called
- **When:** `AsyncClientFactory.get()`
- **Then:** Returns same instance

#### TC-ACF-INT-007: reset() clears cached instance
- **Given:** `create()` called
- **When:** `AsyncClientFactory.reset()` then `get()`
- **Then:** `get()` returns `None`

### Key Implementation Notes

- `AsyncClientFactory.reset()` called in `setup_method` to prevent cross-test caching
- `clear_cli_env` fixture critical: each test starts with clean `FOUNDRY_*` env state
- Temp git repos use `.git` marker directory (not `git init`) for speed and no git dependency
