### Test cases (Given/When/Then)
**TC-055-01 two-way operation inventory (AC-D-013-08).** Given the installed 351-operation parser and dispatch inventory, when it is compared in both directions with the copied skill bundle across all 18 callable namespaces, then every supported operation has exactly one reachable record and there are no missing, extra or duplicate records.
**TC-055-02 unsupported entries not callable (AC-D-013-08).** Given the four legacy Widgets design entries (dev_mode_settings disable, get, pause, set_widget_set), when the bundle is checked, then none is presented as a callable command.
**TC-055-03 signed register audit (AC-D-013-02..05).** Given each operation record, when its signed 351-row trace is audited, then resource, effect, side effect, every applicable input meaning, result and failure interpretation, a coherent example, a source and a reviewer decision are present.
**TC-055-04 copied-bundle offline use (AC-D-013-06,07).** Given all 19 copied skill folders without network access, when local links are checked and a representative mocked or recorded path is exercised in each of the 18 namespaces, then the agent can select, prepare and interpret supported calls and every required local link resolves.
**TC-055-05 shared-claim consistency (AC-D-013-08).** Given the shared concepts repeated across skills (identifiers, access control, output and exit codes, paging, retry and timeout), when a claim is traced across skills, then no skill conflicts with another or with the authoritative Foundry source.
**TC-055-06 harness gate at HEAD (SA-DES-012 section 5).** Given the offline skill gate suite and the per-namespace probe run at the candidate HEAD, then the result is zero missing, extra and duplicate records, examples parsed N of N, zero unresolved local links, the install block present in every command skill, and every leaf part at most 300 lines.
**TC-055-07 install prerequisite and leaf limit (BR-012-09).** Given every command skill SKILL.md and every markdown part, when checked, then each names pal_found_cli with conda `-c t-jet`, pip and uv commands, and each part is at most 300 lines.
**TC-055-NEG-01 missing register row.** Given a supported operation whose record or signed row is absent, when the audit runs, then it fails naming the operation.
**TC-055-NEG-02 callable unsupported entry.** Given a bundle that presents an unsupported Widgets entry as callable, when the check runs, then it fails.
**TC-055-NEG-03 unresolved link.** Given a relative link that escapes its skill folder or targets a missing file, when resolved, then it fails.
**TC-055-NEG-04 conflicting shared claim.** Given a skill whose shared claim contradicts another skill or the authoritative source, when traced, then it fails.
### Expected outputs
351/351 supported operations with exactly one record; zero missing, extra or duplicate; four unsupported entries not callable; every signed row complete; zero unresolved local links across 19 folders; install blocks present; every part at most 300 lines; no conflicting shared claim.
