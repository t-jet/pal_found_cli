# EPIC-015: Develop on Foundry using complete offline skill knowledge

## Business scenario
An agent uses locally available Foundry skills to select a pipeline or application approach, prepare code/configuration and tests, interpret outcomes, and recover from failures without opening public documentation. Authorized tenant access and preprovisioned runtime tools remain explicit prerequisites.

## Acceptance Criteria
- All 36 approved development subsections and separate REST topic meet the complete local task knowledge contract.
- Audit all 20 skills; required knowledge and assets resolve within independently distributed skill folders.
- Independent offline journeys verify decisions, examples, validation and recovery using local content and fixtures; every missing essential fact fails acceptance.
- Preserve 351-operation inventory and link shared CLI defects to FEATURE-012; required unresolved dependencies block acceptance.
- Publish approved skills state to existing GitHub repository after design, grooming, review and QA gates. No new installation or copy instructions.
