Subject: Windows reader retry fix
Created: 2026-10-14T17:16:27
Updated: 2026-10-14T17:16:27
---
Independent full-suite QA reproduced a short Windows PermissionError while opening the counter file during atomic replacement. The write transaction was sound, but load_id_counters and read_link_index did not retry transient reader sharing conflicts. Both readers now retry PermissionError for up to three seconds; atomic replacement already retries writer conflicts. Deterministic tests inject one denied open for each reader. The mixed ticket/link race test passed ten consecutive runs; the full tracker suite passed 439/439, Ruff and scoped whitespace checks pass. Independent QA design 20261014-171612-@tech-lead approved; QA retest underway.
