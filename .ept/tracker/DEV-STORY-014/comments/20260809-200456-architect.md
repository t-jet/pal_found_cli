- **No BinaryDownloadHandler:** no operation returns streamed bytes.
- **Attribution:** NOT required. FR-ATTR-4 scope is `functions.query.*`, `ontologies.query.*`, `media_sets.media_set.*`, `language_models.*` — orchestration is not listed; `invocation_scope` uses `include_attribution=False` (same as models/aip-agents/audit).
- **Access policy:** write set = build.cancel, build.create, schedule.create, schedule.delete, schedule.pause, schedule.replace, schedule.run, schedule.unpause (8 ops). - **Write inputs:** `schedule.create` (JSON `action`/`trigger`/`scope_mode`), `schedule.replace` (full JSON), `build.create` (JSON `target`/`fallback_branches`; optional `force_build`/`retry_count`/`retry_backoff_duration`/`abort_on_failure`/`notifications_enabled`/`branch_name`) — JSON validated locally before client creation per DESIGN-012/013 pattern.
- **Dependencies:** foundry-platform-sdk (v2 orchestration namespace), python-dotenv, common library; pyproject.toml console entry point + package data; tests mirroring sibling suites.
