## Answer — tech-lead decision (2026-08-11)

### Decision
**Implement the 8-operation surface exposed by the installed runtime SDK `foundry-platform-sdk 1.102.0`. Do NOT implement the 12-op DESIGN-022 catalog as written. `DevModeSettingsV2` is OUT of scope.** This follows the established operation-count-correction pattern (streams 17→15, connectivity 15→20, data-health 4→6): the authoritative surface is the runtime/vendored SDK actually installed and used by tests and runtime, not a stale design snapshot.

### Verified installed surface (inspect.signature probes, 2026-08-11)
`foundry_sdk.v2.widgets` mounts exactly these resource clients:

| Resource client | Operations (installed 1.102.0) | In DESIGN-022 scope |
| --- | --- | --- |
| `DevModeSettings` | `enable`, `set_widget_set_by_id` (2) | YES |
| `Repository` | `get`, `publish` (2) | YES |
| `WidgetSet` | `get` (1) | YES |
| `WidgetSet.Release` (nested) | `delete`, `get`, `list` (3) | YES |
| `DevModeSettingsV2` | `enable`, `set_widget_set_manifest` (2) | **NO — new resource, absent from vendored 1.80.0 snapshot and DESIGN-022** |

Total in-scope = **8 operations** (DevModeSettings 2 + Repository 2 + WidgetSet 1 + Release 3). The 4 missing DevModeSettings ops (`disable`, `get`, `pause`, `set_widget_set`) from DESIGN-022 do not exist on the installed SDK and would raise `AttributeError` at runtime; mock-driven tests would mask that.

### Why DevModeSettingsV2 is excluded
It is a NEW resource introduced between the vendored snapshot (tag 1.80.0) and 1.102.0; DESIGN-022 was never validated against it. Adding it to the CLI surface would be scope expansion requiring a design amendment. It remains available for a future story.

### Required amendments (implementer action)
1. Amend DESIGN-022 to the 8-op catalog; update the canonical env-var reference and the canonical metadata allow-list (widgets namespace) to 8 rows.
2. Add write verbs to `AccessControlGuard._WRITE_VERBS`: `disable`, `enable`, `pause`, `set_widget_set` (if the 8-op catalog keeps set_widget_set_by_id) plus `publish`, `delete` (release.delete), per the DESIGN-022 write-set list.
3. Metadata-only policy for the 8-op catalog per the amended allow-list.
4. `version list`-style pagination applies to `release list` (returns `ResourceIterator`).

This unblocks DEV-022 and UNITTEST-022 with a runtime-safe surface.
