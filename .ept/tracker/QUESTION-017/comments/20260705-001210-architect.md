Implementation guidance:
- Add `--dataset-rids` with `dest="dataset_rids"`.
- Keep `--dataset-r` only as a deprecated hidden alias for one compatibility window, if argparse support is cheap.
- Update SKILL.md examples and tests to use `--dataset-rids`.
- Keep the argument value as a JSON array of dataset RIDs.
