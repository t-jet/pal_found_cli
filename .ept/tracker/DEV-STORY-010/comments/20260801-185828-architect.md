Enter AsyncClientFactory.invocation_scope(cfg) before calling _get_client so AsyncFoundryClient is constructed inside the active B3 context. Keep that scope around RetryHandler execution so every retry carries the same X-B3-TraceId, X-B3-SpanId, and X-B3-Sampled values, then restore prior context on success or failure. Add transport-level tests that capture headers for the initial request and retries, plus disabled-tracing and context-restoration cases. Do not emit or claim W3C traceparent/tracestate support.
