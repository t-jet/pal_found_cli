Ten Ontology SDK paginated methods return AsyncResourceIterator and six return page envelopes. PaginationHelper previously received these objects as items, causing serialization failure or incorrect item/token output. _invoke_paginated now uses single-page raw SDK responses for iterator methods, normalizes data and next_page_token, and lets PaginationHelper enforce batch limits. A page-iterator fallback covers SDK-shaped clients without raw responses. Tests cover all 16 operations, empty and oversized pages, resume, metadata, and serialization: 28 focused tool tests and 33 independent QA probes pass. Full tool suite: 1165 passed before the later one-line BUG-018 exit-code correction. Release pin and full feature audit remain open.
