## Business design plan - BA-DES-009 (author ba)

### Business case
Skill users may not know what Palantir Foundry is or what a specific CLI skill covers. Adding a brief platform description to the main skill and short capability descriptions to each specific pal-found-* skill, using text from official Palantir Foundry web pages, makes each skill understandable without leaving the file and supports the self-contained-skill goal (FEATURE-009).

### Acceptance criteria (scope for design)
- Given the main skill, when a user opens it, then it contains a brief description of the Palantir Foundry platform.
- Given any specific CLI skill, when a user opens it, then it contains a brief description of the Foundry capability the tool covers.
- Given a capability description, when it is reviewed, then its text traces to an official Palantir Foundry web page.
- Given all skill descriptions, when they are compared, then no two skills describe the same capability with conflicting facts.
- Given the platform description, when it is checked, then it is brief and understandable by a non-expert.
