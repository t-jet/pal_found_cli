### Test cases (Given/When/Then)
**TC-041-01 task to namespace mapping (AC-D-013-01).** Given a novice agent offline with the general skill, when it reads the primer and navigation map, then for a task such as promoting a dataset branch and exposing its objects it names the Foundry resource, the owning namespaces `pal-found-datasets` and `pal-found-ontologies`, and the next operation, without a web page.
**TC-041-02 copied-folder link resolution (AC-D-013-07).** Given the copied `pal-found` folder, when every relative markdown link is resolved, then each required part (01-platform-concepts, 02-identifiers-auth-access, 03-output-success-failure, 04-shared-options) resolves inside the folder and none escapes it.
**TC-041-03 shared-guidance accuracy (AC-D-013-01,05).** Given the access-control, output, exit-code, paging, retry and timeout guidance, when compared with installed CLI behavior (exit codes 0-9 per ADR-001; default 30 s and streams 120 s per ADR-002) and authoritative Foundry sources, then each statement is accurate, traceable and bounded.
**TC-041-04 namespace independence (AC-D-013-01).** Given one namespace folder plus the primer, when the agent reads it, then it can use that namespace without reading any other namespace.
**TC-041-05 install prerequisite (BR-012-09).** Given `pal-found/SKILL.md`, when the install block is read, then it names `pal_found_cli` and gives conda `-c t-jet`, pip and uv commands.
**TC-041-06 300-line leaf limit (SA-DES-012).** Given every `pal-found` markdown part, when line counts are checked, then each part is at most 300 lines.
**TC-041-NEG-01 undocumented operation.** Given a task whose operation is absent from the map, when the agent looks it up, then the skill directs stop-and-ask rather than guessing a command.
**TC-041-NEG-02 precedence conflict.** Given a conflict between the primer and a namespace part, when both are read, then the namespace part wins for that namespace as documented.
**TC-041-NEG-03 unsupported entries.** Given the 351-operation statement, the zero-operation `geo` and `core` statement, and the four unsupported Widgets entries, when checked against the installed inventory, then counts agree and no unsupported entry is presented as callable.
### Expected outputs
Mapping resolves for representative tasks; zero unresolved local links; shared claims match ADR-001, ADR-002 and the operation catalog; install block present; every part at most 300 lines.
