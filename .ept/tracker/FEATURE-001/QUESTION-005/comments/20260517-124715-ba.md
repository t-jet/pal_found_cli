### 6. Comments & Minor Items

#### 6.1 Clarification Request — FR-SESSION-7 Warning Mechanism
**SRS FR-SESSION-7** states: *\"A warning SHALL be logged (not enforced) when a single agent has more than 5 concurrent active sessions.\"* The SAD SessionManager component mentions active session count checking in sequence diagram 6.5 (`check active session count for agent_rid → warn if >5`), but the warning mechanism is not further specified. **Recommendation:** Confirm in implementation that this is a stderr log at WARNING level (per ADR-005 NDJSON format) and does not produce a CLI exit code or structured error on stdout. This is a documentation completeness note, not a misalignment.

#### 6.2 Clarification Request — SRS §9 Open Items Status
SRS-001 §9 lists 6 open items (OI-1 through OI-6). OI-1 (BA sign-off) is now complete. OI-2 (7 ADR decisions) and OI-3 (retry defaults) are confirmed by ADR acceptance. OI-4 and OI-5 (geo/core namespace confirmation) are marked as assumptions in SAD-001 §12 (AA-3). OI-6 (TOON air-gap install) is documented as a risk in SAD-001 §11. **Recommendation:** Update SRS-001 §9 to mark items as resolved/closed now that design is complete, or migrate remaining open items to implementation tickets.

#### 6.3 Document Index Status Note
The document index (`.ept/docs/document_index.md`) still lists SRS-001 status as \"Draft — Pending BA Sign-off\" and SAD-001 as \"Draft\". Since both documents have been reviewed and approved through this process, the document index should be updated to reflect \"Approved\" status once this QUESTION ticket is resolved.
