## Business Requirements Summary

All requirements derived from `initial_task.md` and 3 rounds of Q&A (47 questions, all answered). Full specification in SRS-001.

### Scope (FR-01)

- **21 Claude Code skill packages**: 20 namespace-specific CLI skills (one per `foundry-platform-python` SDK v2 namespace) + 1 general Foundry knowledge skill
- **355 API v2 operations** exposed across all 20 namespaces
- **No SDK CLI wrapping** — purpose-built agentic CLI (FR-02 resolved: out of scope)

### Access Control Requirements

- **3-tier access model**: Full / Read-only / Metadata-only
- **8-step precedence matrix**: FOUNDRY_ACCESS_TIER (global) → namespace-level flags → operation-level flags; most restrictive wins
- **Operation-level READONLY is independent** of namespace-level (ADR-007)

### Configuration

- **Env var naming convention**: `FOUNDRY_CLI_{NAMESPACE}_{OPERATION}_{PARAM}` (uppercase, underscores)
- **Env var prefix**: `FOUNDRY_CLI_` (not `FOUNDRY_AGENTIC_CLI_`) — resolved in Round 3
- **.env file loading**: python-dotenv; search path per ADR-006 (cwd → $HOME → $XDG_CONFIG_HOME/foundry → /etc/foundry)
- **500+ canonical env var entries** documented in `canonical-env-var-reference.md`

### Output Format

- **TOON** (Tabular Object Output Notation) for uniform arrays ≥2 rows; **JSON** otherwise (ADR-004)
- **TOON library**: `toon >=0.9,<1.0` (beta; version-pinned; JSON fallback if unavailable)
- Response envelope on stdout; structured logs on stderr (ADR-005)

### Non-Functional Requirements (NFR-01–NFR-03)

| ID | Requirement |
|---|---|
| NFR-PLAT-1 | Python 3.10–3.12 support (3.13 deferred) |
| NFR-SEC-1 | UserTokenAuth only; no OAuth2 in MVP; token never logged |
| NFR-PERF-1 | Timeout per ADR-002 (30s connect / 300s read for binary) |
| NFR-MAINT-1 | Single common module (`_foundry_cli_common.py`); copied per skill |

### Impact to End-to-End Business Processes

- **AI agents** using Foundry data via Claude skills gain structured CLI access to all 355 operations
- **Access control** enforces least-privilege without modifying Foundry platform settings
- **Session management** enables stateful AIP Agent interactions (`.foundry-data/` persistence)

### Assumptions and Risks

- SDK `AsyncFoundryClient` is production-stable for all 20 namespaces (AA-1)
- All 355 enumerated operations are available on target Foundry instance (AA-2)
- `geo` and `core` namespaces have 0 public CLI-callable operations (AA-3 — confirmed)
- Key risk: TOON library API instability (version-pinned; JSON fallback documented)
- Key risk: SDK update breaking CLI (version locked; explicit review required)

### Request Rate / Data Size

- **Pagination**: all paginated responses use `PaginationHelper` in `_foundry_cli_common.py`
- **Binary downloads**: 1.5 GB confirmed limit (Round 3 Q3.1 resolution); `BinaryDownloadHandler` with streaming
- **Retry**: configurable via `RetryHandler`; defaults per ADR-002
