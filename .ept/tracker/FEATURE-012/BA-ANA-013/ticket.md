# Analyze offline Foundry skill knowledge requirements

## Business case

Agents new to Palantir Foundry need enough knowledge in the distributed skills to choose an operation, enter values with the right Foundry meaning, understand its effect, and interpret the result without internet access or another guide.

## Acceptance criteria

- Produce a business analysis deliverable under `.ept/docs/deliverables/business_analysis/` with a finite set of requirements and testable acceptance criteria for FEATURE-012.
- Cover the Foundry platform primer, capability behavior, every supported operation's effect, every parameter's Foundry meaning, result interpretation, side effects, and offline use.
- Analyze impact on end-to-end use, access restrictions, request rates, data size, assumptions, risks, and dependencies on FEATURE-008/009.
- Identify scope boundaries and any questions requiring Project Owner or architect review.
- Request the mandatory Project Owner and architecture reviews after the analysis is complete.
