## Open-stage plan (Open → In Progress → Resolved)

Mirrors the established DEVOPS-005 (datasets / common components) and DEVOPS-007 (filesystem) verification pattern. Foundry-admin is the newest sibling (DEV-009/UNITTEST-009/CODEREVIEW-009/TESTCASE-009 all Closed).

### Acceptance Criteria (Given/When/Then)
- **AC1** `python -m pip install -e .` exits 0 and registers the `foundry-admin` console script.
- **AC2** `foundry-admin --help` exits 0 and lists the admin resource groups (user, organization, group, group_member, role, role_membership, role_assignment, marking, enrollment_request, authentication_provider, token, etc.).
- **AC3** `python -m foundry_cli.admin.scripts.foundry_admin_cli --help` exits 0 with the same parser help.
- **AC4** Module/package contents: `foundry_admin_cli.py` built into the wheel; `OP_SPECS` exposes 66 operations; `console_main` present.
- **AC5** Skill package: `.claude/skills/foundry-admin/SKILL.md` frontmatter `name: foundry-admin`; launcher `.claude/skills/foundry-admin/scripts/foundry_admin_cli.py` present.
- **AC6** `pyproject.toml` `[project.scripts]` has `foundry-admin = "foundry_cli.admin.scripts.foundry_admin_cli:console_main"`.
- **AC7** Packaging config: build-system setuptools≥68, py 3.11+, deps include foundry-platform-sdk + python-dotenv + requests; mypy/ruff/coverage(≥80% gate) configured; ruff per-file-ignores include `admin/scripts/*.py` E402.

### Deliverables (this ticket)
1. Packaging/install verification evidence (real terminal output): install exit code, `--help` exit codes, op-count.
2. Entry-point + skill package presence confirmation.
3. Final regression/coverage + CI-matrix evidence — **deferred until TESTEXEC-009 closes** (depends-on link LINK-00360 gates this final block; the package itself is verified independently).

### Deployment plan steps
1. Local test-env deploy: `python -m pip install -e .` (test environment = a clean/effective venv).
2. Console smoke: `foundry-admin --help`; module smoke: `python -m foundry_cli.admin.scripts.foundry_admin_cli --help`.
3. Artifact presence audit: module file, SKILL.md, launcher, pyproject entry, OP_SPECS count.
4. (Deferred) Full regression + coverage + CI matrix (Ubuntu/Windows 3.11/3.12) once QA closes TESTEXEC-009.
