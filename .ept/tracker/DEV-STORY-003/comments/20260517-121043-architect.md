### Technical Scope

**AccessControlGuard** — Python class implementing the 8-step precedence model from SRS-001 §4.2 (FR-ACL-5):

1. Step 1: `FOUNDRY_AGENTIC_CLI_{NS}_{CLASS}_{OP}_ENABLED=false` → BLOCKED
2. Step 2: `FOUNDRY_AGENTIC_CLI_{NS}_ENABLED=false` → BLOCKED
3. Step 3: `{NS}_{CLASS}_{OP}_READONLY=false` → WRITE PERMITTED (override)
4. Step 4: `{NS}_READONLY=false` → WRITE PERMITTED (override)
5. Step 5: `FOUNDRY_AGENTIC_CLI_READONLY=true` → ALL WRITES BLOCKED
6. Step 6: `{NS}_METADATA_ONLY=false` → CONTENT READS PERMITTED (override)
7. Step 7: `FOUNDRY_AGENTIC_CLI_METADATA_ONLY=true` → CONTENT READS BLOCKED + WRITES BLOCKED
8. Step 8: Default → FULL ACCESS

- Raises `AccessControlError` (exit code 8 per ADR-001) on block
- Operates as a gate before RetryHandler reaches the SDK (SAD-001 §4)
- Must classify operations as read/write/content-read for tier evaluation
- Metadata allow-list (162 permitted / 193 blocked operations) drives Step 7 content-read decisions

**PaginationHelper** — Python class for transparent multi-page iteration:

- Manages `--page-size`, `--page-token`, `--batch-pages` CLI arguments
- Aggregates results across pages into a single result set
- Writes pagination metadata JSON to stderr with `# ---metadata-start---` separator (ADR-005)
- Coordinates with OutputFormatter for result emission (SAD-001 §4)

### Dependencies

- **DEV-STORY-001** (ConfigLoader, AuthProvider, AsyncClientFactory): AccessControlGuard depends on ConfigLoader for env var resolution. DEV-STORY-001 is currently in status `New`.
- **DEV-STORY-002** (RetryHandler, ErrorSerializer, OutputFormatter, LogSetup): AccessControlError maps to exit code 8 handled by ErrorSerializer; PaginationHelper coordinates with OutputFormatter. DEV-STORY-002 is currently in status `Analysis`.
