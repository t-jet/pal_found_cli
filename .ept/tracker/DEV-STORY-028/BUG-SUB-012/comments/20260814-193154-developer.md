## Root cause

publish.yml conda job upload step (line 85) uses glob conda-channel/*/*.tar.bz2. conda-build 26.7.0 produces only .conda artifacts (e.g. .ept/tmp/conda-channel/noarch/pal_found_cli-0.1.0-py_0.conda, 80499 bytes, HEAD 5746815), so the glob matches zero files and the token-present branch can never upload (TESTEXEC-028 COND-TC-012 FAIL).

## Reproduction

Glob simulation: '*.tar.bz2' -> 0 matches; '*.conda' -> 1 match.

## Fix plan

1. publish.yml: change upload glob to conda-channel/*/*.conda (line 85).
2. tests/test_release_artifacts.py: add regression assertion that the conda upload glob targets *.conda.
3. Verify: YAML parse of publish.yml; glob simulation (0 tar.bz2 / 1 conda); pytest tests/test_release_artifacts.py exit 0.

References: SA-DES-005 UC-4, AC-D-006-01.
