## Fix implemented and verified (2026-08-14)

### Root cause (confirmed)
`publish.yml` conda job upload step targeted the glob `conda-channel/*/*.tar.bz2`, but conda-build 26.7.0 (per QUESTION-118 answer) produces only `.conda` artifacts. The glob matches 0 files, so the token-present branch could never publish (TESTEXEC-028 COND-TC-012 FAIL). Prior fix plan: comments 20260814-192934-developer / 20260814-193154-developer.

### Fix applied
- `.github/workflows/publish.yml`, conda job, "Publish conda package when channel permission exists" step (line 85): upload glob changed from `conda-channel/*/*.tar.bz2` to `conda-channel/*/*.conda`.
- `tests/test_release_artifacts.py`: added regression test `test_conda_upload_glob_targets_conda_artifact_format` asserting the upload command targets `*.conda` and no longer references `*.tar.bz2`.

### Verification evidence
