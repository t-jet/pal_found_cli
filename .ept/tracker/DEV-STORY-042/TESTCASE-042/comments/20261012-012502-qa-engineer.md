### Test cases (Given/When/Then)
**TC-042-01 inventory one-to-one (AC-D-013-08).** Given the 38 frozen identity operation keys, when record headings `### <resource>.<operation>` in references/01-identity-auth-users.md and references/02-identity-groups-roles.md are enumerated, then every key has exactly one record and no extra or duplicate record exists.
**TC-042-02 record completeness sample (AC-D-013-02..05).** Given one record per resource client, for example user.get, group.create, role.get, enrollment_role_assignment.add and authentication_provider.preregister_user, when each is read, then resource, observable effect and side effect, input meaning (required or optional, form or unit, effect of change), success/empty/page/pending/error interpretation and a coherent example are correct against the installed CLI.
**TC-042-03 offline copied-folder representative run (AC-D-013-06,07).** Given the copied folder with no network, when a novice agent follows one example per client with mock or recorded output, then it chooses valid inputs, interprets the result and next operation, and every required local link resolves.
**TC-042-04 install prerequisite (BR-012-09).** Given pal-found-admin/SKILL.md, when the install block is read, then it names pal_found_cli and gives conda `-c t-jet`, pip and uv commands.
**TC-042-05 300-line leaf limit (SA-DES-012).** Given every markdown part, when line counts are checked, then each part is at most 300 lines.
**TC-042-06 paged operations (AC-D-013-04).** Given group.list, user.list and group_member.list, when a short page with a returned token is read and then resumed with `--page-token`, then the short or empty page is distinguished from incomplete retrieval and the next page is documented.
**TC-042-NEG-01 missing record.** Given a frozen key with no heading, when the inventory check runs, then it fails naming the key.
**TC-042-NEG-02 unsupported call.** Given an operation not in the register, when the skill is read, then it is not presented as callable.
**TC-042-NEG-03 stale example.** Given an example whose command selects a different resource.operation than its heading, when parsed against the frozen parser, then it fails.
**TC-042-NEG-04 unresolved link.** Given a relative link that escapes the folder or targets a missing file, when resolved, then it fails.
### Expected outputs
