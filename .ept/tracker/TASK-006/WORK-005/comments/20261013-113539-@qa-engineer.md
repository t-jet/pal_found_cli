# QA test design for assigned semantic rows

Scope: WORK-005, FEATURE-012. Audit, Connectivity, Checkpoints, Data Health, AIP Agents, Functions; 53 frozen operations (2+20+3+6+15+7). Compare copied skill records with current CLI parser/dispatch and pinned local Foundry SDK. BA-DES-013 section 3 and SA-DES-012 sections 3-4 define acceptance.

Preconditions: Full skill folders, current CLI source, local SDK source, frozen inventory, and source-hash register available. No live Foundry writes. Tech Lead/Architect approval required before execution.

Scenarios: (1) Given each frozen operation, when tracing parser, dispatch, SDK and record, then one reachable record names exact command, all inputs, resource, effect and side effects. (2) Given success, empty, paged, pending and binary outcomes where applicable, when reading record against CLI/SDK paths, then output and follow-up meaning match. (3) Given invalid input, auth, permission, access guard, rate limit, timeout, server or missing resource where applicable, when tracing error paths, then record states exit meaning and uncertainty accurately. (4) Given examples and copied folder, when following links offline, then examples use accepted inputs and all required parts resolve.

Edges: empty collection with continuation token, final/short page, omitted versus explicit defaults, zero or maximum bounded payload, async accepted versus complete, concurrent or retried operation where relevant. Negative cases: malformed JSON, missing required ID, invalid enum/date, unauthorized call, simulated timeout/network failure.

Expected outputs: One pass/fail decision per operation with record/CLI/SDK SHA-256, reviewer date and grounded note; each fail names BUG ticket. CLI exits must match taxonomy 0 success, 1 input, 2 auth, 3 permission, 4 not found, 5 timeout, 6 server, 7 rate limit, 8 access guard, 9 config where exercised. No sign-off from structural checks alone.

Test data: illustrative RIDs, dates, JSON bodies and mocked SDK responses from each method signature/result model; no credentials. Report per-namespace counts and open defects to TASK-006.
