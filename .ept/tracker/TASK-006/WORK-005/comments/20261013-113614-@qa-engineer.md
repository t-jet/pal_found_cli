# Scope
Independent semantic review of 50 frozen records: language_models 2, models 23, orchestration 20, sql_queries 5. Compare each distributed operation record with the installed CLI parser, dispatch and output path plus local SDK client/model source. No live Foundry mutation.

# Preconditions
Use frozen keys from pal_found_cli_skills/tests/test_offline_skill_gate.py and local SDK source at .ept/docs/customer_input/foundry-platform-python. Capture current record, CLI and SDK SHA-256 per row. Read SA-DES-012 and BA-DES-013. Tech Lead must approve this design before execution.

# Scenarios
- Given each frozen key, when locating parser, dispatch, SDK method and skill record, then find one exact callable command and one complete record with no unsupported flags.
- Given each required and optional input, when comparing types, defaults and meaning, then examples and input guidance match parser and SDK.
- Given read, write, async, paged or streaming results, when comparing operation effects and outputs, then skill states observable CLI output, side effects, continuation and uncertainty correctly.
- Given SDK error paths and CLI exception handling, when comparing failure guidance, then permissions, missing objects, invalid input and incomplete async results are described without invented success states.

# Edge and negative cases
Check empty collections, first and last pages, continuation cursor, optional omissions, zero and maximum documented bounds, JSON versus string input, repeated identifiers, pending async result, malformed JSON, unauthorized request, timeout and network failure where each operation supports the path. Treat unsupported paths as not applicable, with source reason.

# Expected outputs and data
Each row gets PASS or FAIL and source hashes; FAIL requires linked BUG with exact repro. CLI error taxonomy: 0 success, 1 input, 2 authentication, 3 permission, 4 missing, 5 timeout, 6 server, 7 rate limit, 8 access guard, 9 configuration, subject to exact implementation. Use placeholder RIDs, JSON payloads and local mocked responses; no credentials or live mutations. Final summary names counts and open defects. Design is source comparison, not a claim that live API outcomes passed.
