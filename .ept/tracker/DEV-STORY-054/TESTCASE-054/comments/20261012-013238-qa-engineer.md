### Test cases (Given/When/Then)
**TC-054-01 inventory one-to-one (AC-D-013-08).** Given the frozen keys, when record headings are enumerated in each namespace SKILL.md and references, then all 17 keys have exactly one record each and no extra or duplicate record exists.
**TC-054-02 record completeness sample (AC-D-013-02..05).** Given third_party_application.get, website.deploy, website.undeploy, version.upload, version.upload_snapshot, version.list, dev_mode_settings.enable, dev_mode_settings.set_widget_set_by_id, release.list, repository.publish and widget_set.get, when each is read, then resource, effect and side effect, input meaning, result and failure interpretation and a coherent example are correct against the installed CLI.
**TC-054-03 offline copied-folder representative run (AC-D-013-06,07).** Given the copied folders with no network, when a novice agent follows one example in each namespace with mock or recorded output, then it chooses valid inputs, interprets the result and next operation, and every required local link resolves.
**TC-054-04 install prerequisite (BR-012-09).** Given the two SKILL.md files, when the install blocks are read, then each names pal_found_cli and gives conda `-c t-jet`, pip and uv commands.
**TC-054-05 300-line leaf limit (SA-DES-012).** Given every markdown part of both folders, when line counts are checked, then each part is at most 300 lines.
**TC-054-06 bounded zip upload semantics (AC-D-013-03,09).** Given version.upload, version.upload_snapshot and repository.publish, when the records are read, then the local zip input, the bounded upload size limit and the release effect are stated.
**TC-054-07 unsupported legacy Widgets entries (AC-D-013-08).** Given dev_mode_settings disable, get, pause and set_widget_set, when the widgets skill is read, then each is documented as unsupported and not callable, appears only in a negative context, and no `pal-found-widgets dev-mode-settings <operation>` invocation is presented.
**TC-054-08 page and dev mode semantics (AC-D-013-04,05).** Given release.list with page tokens and dev_mode_settings.enable, when the records are read, then the paging, the 24-hour dev mode expiry and the effect on other users are stated.
**TC-054-NEG-01 missing or duplicate record.** Given a key with no heading or two headings, when the inventory check runs, then it fails naming the key.
**TC-054-NEG-02 unsupported presented as callable.** Given an unsupported legacy Widgets entry, when the skill is read, then presenting it as callable fails the check.
**TC-054-NEG-03 stale example.** Given an example selecting a different resource.operation than its heading, when parsed, then it fails.
**TC-054-NEG-04 unresolved link.** Given a relative link that escapes the folder or targets a missing file, when resolved, then it fails.
