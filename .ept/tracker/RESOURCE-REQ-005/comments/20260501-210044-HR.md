### Delivery Approach

The DevOps Engineer agent will be created as a new `.agent.md` file following the canonical agent definition template at `.ept/resources/agent_definition_template.md`.

**File location**: `.github/agents/devops-engineer.agent.md`  
**Agent identifier**: `devops-engineer`  
**Registry entry**: Will be added to `.ept/resources/available_resources.md` under a new "DevOps & Infrastructure Agents" section.

---

### Confirmed Scope

The agent will be scoped to the following responsibilities:

1. **CI/CD Pipeline Setup**: Design and implement GitHub Actions workflows (lint, type-check, test, security scan, publish) for the Foundry CLI source repository
2. **DEVOPS Sub-task Execution**: Execute all 23 DEVOPS sub-tasks during the Deployment stage of each DEV-STORY (deploy, verify, document)
3. **Python Packaging Infrastructure**: Configure `pyproject.toml`, build system (poetry or setuptools), release publishing workflow
4. **Environment & Secrets Configuration**: Manage Foundry API token handling, `.env` templates, environment variable schemas, integration with secrets managers
5. **Rollback & Health Checks**: Establish rollback procedures and deployment health checks for each namespace skill deployment
6. **Collaboration**: Coordinate with Tech Lead on performance and scalability requirements for deployment configuration

### Tool Selection

The DevOps Engineer requires:
- `execute/*` — run CI commands, shell scripts, deployments
- `read/*` — inspect configuration files, logs, CI output
- `edit/*` — create and modify CI/CD workflows, packaging configs, env templates
- `search/*` — locate relevant files and tickets
- `agent/runSubagent` — delegate ticket operations to `ticket-helper`
- `web/*` — consult GitHub Actions documentation, packaging standards, security advisories
- `todo` — multi-step task tracking
