## Gherkin scenarios
F085-01 Execution.cancel: Given a submitted synthetic execution ID and authorized mock; when client.functions.Execution.cancel(id, preview=True, request_timeout=5) sends POST /api/v2/functions/executions/{executionId}/cancel; then JSON CancelExecutionResponse.id equals request ID. Repeat cancel returns documented idempotent response. Named CancelExecutionPermissionDenied is surfaced; transport timeout leaves outcome uncertain and requires get_result reconciliation, not blind resubmission.
F085-02 Execution.get_result: Given an execution ID; when get_result(id, timeout=0, preview=True, request_timeout=5) posts to /getResult; then body is {"timeout":0} and RunningExecution(type=running) is decoded. Given timeout omitted, body is {}. Given timeout=280 and sufficient client timeout, success yields SucceededExecution(type=succeeded,value). A service execution failure raises its service error; GetResultExecutionPermissionDenied stays a denial. Do not claim the SDK clamps values above 280 locally; that is a server contract.
F085-03 Query.execute: Given a global Query API name and {"amount":2}; when execute(name, parameters=..., version="1.0.0", branch="master", preview=True, request_timeout=5) runs; then POST /queries/{queryApiName}/execute carries parameters/version/branch JSON, preview query, and ExecuteQueryResponse.value. Ontology-scoped execution must use its distinct ontology endpoint. ExecuteQueryPermissionDenied surfaces; a lost response leaves effect/result uncertain.
F085-04 Query.execute_async: Given a Query and optional ontology, branch, version, transaction ID; when execute_async sends POST /executeAsync; then ontology/parameters/version/branch are body fields, transactionId and preview are query fields. Submitted variant yields ExecutionSubmitted.execution_id for finite polling; completed variant yields ExecutionCompleted.value without polling. Denial raises ExecuteAsyncQueryPermissionDenied; unknown response is reconciled by authorized execution ID/status if available.
F085-05 Query.get: Given a Query API name; when get(name, version="1.0.0", preview=True) sends GET /queries/{queryApiName}; then version/preview are query selectors and typed Query metadata is returned. Missing query raises QueryNotFound; response identity/version must match the selected query.
F085-06 Query.get_by_rid: Given a valid Function RID; when get_by_rid(rid=..., include_prerelease=True, version=None, preview=True) sends GET /queries/getByRid; then rid/includePrerelease/preview are query parameters and typed Query RID matches. Explicit version is sent as version. Without version, includePrerelease controls stable versus prerelease consideration. GetByRidPermissionDenied is surfaced; no silent fallback to another RID.
F085-07 Query.get_by_rid_batch: Given 1 and 100 GetByRidQueriesBatchRequestElement objects including per-element RID/version/includePrerelease; when get_by_rid_batch(body, preview=True) sends POST /queries/getByRidBatch; then JSON list preserves input selectors and GetByRidQueriesBatchResponse.data contains only visible/existing Query records. Missing or denied records may be omitted, so omission is not proof of absence. Empty and 101-element inputs fail local annotated length validation before HTTP.
F085-08 Query.streaming_execute: Given a global or permitted ontology Query; when streaming_execute(name, parameters=..., preview=True) opens POST /streamingExecute with Accept text/event-stream; then an AsyncSseContextManager yields typed StreamingExecuteQueryResponse data batches and error event, and the context closes after finite event, decoded-byte, and deadline budgets. Preserve prior data on error, stop on error, and surface StreamingExecuteQueryPermissionDenied on HTTP denial. One stalled or oversized frame remains outside the between-event hard bound.
F085-09 Query.streaming_execute_events: Given same inputs; when streaming_execute_events opens POST /streamingExecuteEvents; then the distinct path and request type are used, typed data/error events are consumed finitely, and context closes on completion, exception, or budget stop. Denial raises StreamingExecuteEventsQueryPermissionDenied. Both SSE methods have context-manager return types, not ordinary eager JSON responses.
F085-10 ValueType.get: Given a permitted ValueType RID; when get(rid, preview=True) sends GET /valueTypes/{valueTypeRid}; then returned ValueType RID and latest metadata match request. ValueTypeNotFound surfaces for missing RID; no invented version selector on this method.
F085-11 VersionId.get: Given ValueType RID and version ID; when ValueType.VersionId.get(value_type_rid, version_id_version_id, preview=True) sends GET /valueTypes/{valueTypeRid}/versionIds/{versionIdVersionId}; then typed VersionId identity matches both selectors. VersionIdNotFound surfaces for missing version and a mismatched response ID is rejected by fixture.

## Shared adverse and acceptance checks
For all 11 operations, compare signature, HTTP method/path, required parameters, body/query/header placement, typed result, named error, release stage, preview handling, ordinary/raw/stream wrapper availability, and source silence against frozen SDK. Missing required inputs fail local validation before transport. Mock 401/403, HTTP timeout and invalid response separately; preserve specific SDK error names and make no universal authorization or idempotency claim. Query parameters use tenant-derived schema-compatible values, including null/nested DataValue where metadata permits. Explicit version plus branch must refer to a version on that branch. Query execution effects must be checked against the tenant's authorized read-only Query policy; do not infer it from a successful HTTP receipt. Raw and streaming response wrappers must close. All examples use synthetic IDs and a fake token.
