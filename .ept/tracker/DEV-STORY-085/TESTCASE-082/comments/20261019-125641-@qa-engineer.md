## Executable Gherkin index
Detailed inputs, responses, adverse oracles and source identity are in TESTCASE-082 comments 20261019-125426-@qa-engineer and 20261019-125502-@qa-engineer. These 11 scenarios are the formal case IDs.

```gherkin
Scenario: F085-01 cancel a submitted execution
  Given a permitted submitted execution ID and fake transport
  When Execution.cancel sends POST /executions/{executionId}/cancel
  Then CancelExecutionResponse.id matches and denial or timeout follows the documented recovery path

Scenario: F085-02 poll an execution
  Given a permitted execution ID with running then succeeded replies
  When Execution.get_result sends POST /executions/{executionId}/getResult with a finite timeout
  Then the running and succeeded tagged variants decode without confusing server hold time with client timeout

Scenario: F085-03 execute a global query
  Given a permitted global Query with typed parameters and selected version
  When Query.execute posts to /queries/{queryApiName}/execute
  Then parameters, branch, version and preview reach the expected wire locations and the value decodes

Scenario: F085-04 submit asynchronous query
  Given a permitted Query and optional ontology, branch, version and transaction selectors
  When Query.execute_async posts to /queries/{queryApiName}/executeAsync
  Then submitted yields executionId for polling or completed yields the value without polling

Scenario: F085-05 read a query by API name
  Given a permitted Query API name and version
  When Query.get requests /queries/{queryApiName}
  Then selected metadata matches, or QueryNotFound is raised

Scenario: F085-06 read a query by RID
  Given a permitted Function RID
  When Query.get_by_rid requests /queries/getByRid with includePrerelease and version selectors
  Then returned RID matches, or GetByRidPermissionDenied is raised

Scenario: F085-07 batch read queries by RID
  Given 1 or 100 request elements with per-element selectors
  When Query.get_by_rid_batch posts to /queries/getByRidBatch
  Then visible records decode and missing or denied records can be omitted; zero or 101 elements fail before transport

Scenario: F085-08 stream query values
  Given a permitted Query and framed data then error SSE events
  When Query.streaming_execute posts to /queries/{queryApiName}/streamingExecute
  Then prior batches survive the typed error and the context closes within finite budgets

Scenario: F085-09 stream query events
  Given a permitted Query and framed SSE events
  When Query.streaming_execute_events posts to /queries/{queryApiName}/streamingExecuteEvents
  Then the distinct request type yields typed events and the context closes after completion or budget stop

Scenario: F085-10 get latest value type
  Given a permitted ValueType RID
  When ValueType.get requests /valueTypes/{valueTypeRid}
  Then the latest typed value type matches the RID or ValueTypeNotFound is raised

Scenario: F085-11 get specific value type version
  Given a permitted ValueType RID and version ID
  When ValueType.VersionId.get requests /valueTypes/{valueTypeRid}/versionIds/{versionIdVersionId}
  Then typed version identity matches both selectors or VersionIdNotFound is raised
```

Shared cases use preview=true, a synthetic bearer token, explicit request_timeout, 401/403, timeout, malformed response, raw/stream closure, and an unexpected-socket trap. They run only after independent case approval.
