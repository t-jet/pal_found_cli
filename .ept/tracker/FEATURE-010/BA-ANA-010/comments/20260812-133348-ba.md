## Analysis plan + DoD compliance evidence - BA-ANA-010 - Open to In Progress
### Business case
FEATURE-010 (Project Owner requirement 2026-08-12): rename the foundry_ prefix to pal_found_ across all three projects to avoid confusion with other projects and with Microsoft Foundry. Scope covers repository names, the Python package name, console entry points, agent skill names, skill folder layout, and documentation references. The rename is cross-cutting: it affects every other feature under EPIC-009 and EPIC-010, so the business analysis must define the target naming decisions and their downstream impact.
### Acceptance criteria (prepared, full set in deliverable)
- AC-010-01: Given the three repositories, when the rename is applied, then repository names carry the pal_found_ prefix as confirmed by the Project Owner.
- AC-010-02: Given the Python package, when released, then its distribution and import name use the confirmed target name.
- AC-010-03: Given the CLI tool, when installed, then its console commands use the confirmed entry-point prefix.
- AC-010-04: Given the agent skills, when distributed, then skill names and folder layout use the confirmed prefix.
- AC-010-05: Given published documentation, when reviewed, then no stale foundry_ references remain except historical notes.
