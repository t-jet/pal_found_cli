## Business design plan - BA-DES-011 (author ba)

### Business case
The three projects use the foundry_ prefix in public names (repos, Python package, CLI commands, agent skills). Project Owner confirmed on 2026-08-12 (QUESTION-072..075, Closed) that the prefix changes to pal_found_ (repos + package) and pal-found- (CLI entry points + skill folders). Because the projects are still in design, the rename must be designed now so target names are built in from the start across FEATURE-002..009 design work.

### Acceptance criteria (scope for design)
- Given the three repositories, when the rename is applied, then every repository name uses the confirmed pal_found_ prefix.
- Given the Python package, when a user installs it, then the installed package carries the confirmed name.
- Given the CLI tool, when a user runs its commands, then every command uses the confirmed pal-found- prefix.
- Given the agent skills, when they are distributed and loaded, then skill names and folder layout use the confirmed pal-found- prefix.
- Given the published documentation, when a user reads it, then no active foundry_ name remains outside clearly marked historical notes.
- Given an existing user of the tool, when the rename ships, then the tool performs identically; only names change.
