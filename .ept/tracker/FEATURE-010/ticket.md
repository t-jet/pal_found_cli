# FEATURE-010: Rename foundry_ prefix to pal_found_ across all three projects

## Description

Business requirement (Project Owner, 2026-08-12): all three projects must change the 'foundry_' prefix to 'pal_found_' to avoid confusion with other projects and Microsoft Foundry. Repositories, CLI tool, and package must be renamed accordingly. Scope covers: the three repository names (foundry_cli, foundry_cli_tool, foundry_cli_skills), the Python package (foundry_cli), console entry points (foundry-*), agent skill names (foundry-*), skill folder layout, and documentation references. This is cross-cutting: it affects design of all other features under EPIC-009 and EPIC-010. Exact target names (repo names, package name, entry-point names, skill names) are to be confirmed during analysis.
