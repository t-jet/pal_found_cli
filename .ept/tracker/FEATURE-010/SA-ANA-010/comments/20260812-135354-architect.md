## Architecture approach and document changes - SA-ANA-010

### Architecture approach
Pure identity rename, zero functional change. Every project-owned identifier carrying the foundry_ prefix moves to pal_found_; Palantir-owned names stay (foundry_sdk, foundry-platform-sdk, FOUNDRY_TOKEN, FOUNDRY_HOSTNAME). One canonical list of 19 names (main skill + 18 namespaces) drives repos, package, entry points, and skills, so the rename is one coordinated sweep, not per-file edits. CI/CD and packaging config must change atomically with code or the pipeline breaks at build time.

### Affected services and interfaces
- Three repos: foundry_cli (design/docs/tracking, t-jet/foundry_cli.git), foundry_cli_tool and foundry_cli_skills submodules (t-jet/foundry_cli_tool.git, t-jet/foundry_cli_skills.git; verified 2026-08-12)
- Python package foundry_cli (src tree, 18 namespace subpackages + common); distribution foundry-cli in pyproject.toml
- 18 console entry points foundry-* in [project.scripts] (verified count)
- 19 skill folders in .claude/skills (main skill foundry + 18 namespace skills; verified)
- Docs: document_index.md, SRS-001, SAD-001, ENV-REF-001 (789 FOUNDRY_AGENTIC_CLI occurrences measured 2026-08-12), metadata-allow-list, DESIGN/DEVOPS/TESTCASE/TESTEXEC reports, .env.example (19 vars)
- Build/CI: pyproject.toml, ci.yml (--cov=foundry_cli), publish.yml (PyPI), tests (18 test_foundry_*_cli.py files plus ~50 files importing foundry_cli.*)

### Technology stack (unchanged)
Python 3.11+, setuptools PEP 517 build, foundry-platform-sdk, python-dotenv, requests; pytest, pytest-cov, mypy, ruff, bandit; GitHub Actions (ci.yml, publish.yml); pip and conda channels. No new dependencies.

### Implementation and migration approach
Phased and gated. Phase 0: PO naming decisions (BA-ANA-010 QUESTIONS-072..075, blocking). Phase 1: repo renames plus submodule URL fixes; GitHub redirects preserve history. Phase 2: package and pipeline (src move, imports, entry points, config, CI, tests; gate full suite green, coverage >= 80%, 18 entry-point smoke). Phase 3: skills rename in both layouts (.claude/skills and .agents/skills per FEATURE-006). Phase 4: docs sweep. Phase 5: release 0.2.0 under the new name on pip and conda with a migration note. Downstream consumers SA-ANA-002..009 receive impact comments once the PO confirms.
