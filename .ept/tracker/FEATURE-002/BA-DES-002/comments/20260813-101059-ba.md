## Business design plan - BA-DES-002 (author ba)

### Business case
Public GitHub hosting of the three repositories (pal_found_cli, pal_found_cli_tool, pal_found_cli_skills) is the prerequisite for every downstream distribution channel: pip (FEATURE-004), conda (FEATURE-005), git-based skill distribution (FEATURE-007) and harness-agnostic skill access (FEATURE-006). Without it users and agents cannot reach the tool or skills.

### Acceptance criteria (scope for design)
- Given a user without a GitHub account, when they open any repository URL, then all content is readable without authentication.
- Given a user with git, when they clone any of the three repositories, then the clone succeeds without credentials.
- Given a visitor, when they browse a repository, then issues and pull requests are visible and openable.
- Given a release published by an owner, when a visitor follows the release link, then artifacts are downloadable without login.
- Given a repository later made private, when a user without access retries a clone, then the operation fails and no content is exposed.
- Given any repository content, when publication is prepared, then no secrets or credentials are present (scan passes).
