## Acceptance criteria (prepared)
- AC1: Given a user without any Foundry account, When they open a repository URL, Then they can view all content without authentication.
- AC2: Given a user, When they run git clone on any of the three repositories, Then the clone succeeds without credentials.
- AC3: Given a contributor, When they open a pull request, Then the contribution workflow is public and visible to all.
- AC4: Given a repository owner, When they push a release, Then public users can access released artifacts without login.
