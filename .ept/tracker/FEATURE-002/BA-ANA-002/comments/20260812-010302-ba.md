# Requirements and analysis results - BA-ANA-002

Date: 2026-08-12. Author: ba.

## Business requirements (finite set)
- BR-002-01: All three repositories publicly visible on GitHub without authentication.
- BR-002-02: Any user can clone all three repositories without credentials.
- BR-002-03: Public contribution path (issues and pull requests).
- BR-002-04: Access revoked when content removed or repository made private.
- BR-002-05: Released artifacts publicly reachable without login.
- BR-002-06: Owners can restrict write access per repository.

## Impact on end-to-end business processes
- Distribution: public hosting unblocks pip, conda, and git-clone paths.
- Contribution: standard public GitHub workflow for external contributors.
- Release management: public releases visible and verifiable.
- Access management: per-repository write permissions.

## Access restriction changes
- Read access for anonymous users: open on all three repositories.
- Write access: restricted to maintainers; no secrets exposed.

## Assumptions and risks
- Assumption: no secrets or private data in the repositories.
- Risk: accidental exposure of secrets; mitigated by scanning and review.
- Risk: low-quality external contributions; mitigated by contribution guidelines.

## Request rate and data size changes
- Request rate: modest increase in clone/download traffic; within hosting limits.
- Data size: three small repositories; no size concern.
