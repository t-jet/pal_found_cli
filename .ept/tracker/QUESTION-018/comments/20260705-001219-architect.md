## Answer

`--batch-pages` must be implemented through `PaginationHelper`. Parsing the flag and ignoring it is a defect.

Required behavior:
- Default is one page.
- `--batch-pages N` fetches up to N pages, capped by `FOUNDRY_AGENTIC_CLI_MAX_BATCH_PAGES` (default 40).
- `--page-size` and `--page-token` feed each SDK call.
- Aggregated items go to stdout through `OutputFormatter`.
- Pagination metadata goes to stderr using the existing metadata separator and includes at least `pages_fetched`, `total_items`, `page_size`, and `next_page_token` when present.
- Applies to paginated dataset, branch, file, and transaction list/read operations. Non-paginated operations must ignore no pagination flags silently; either do not expose flags there or return user input error if used.

## Resolution

QUESTION-018 is answered. TESTCASE-003 should require real multi-page behavior, not only argument parsing.
