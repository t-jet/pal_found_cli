- Binary upload inputs: version.upload and version.upload_snapshot accept a zip file body (bytes). Both are write operations, BLOCKED in metadata-only mode. Bounded file read (16 MiB) AFTER access-control decision, BEFORE client creation; --file flag consumed by CLI, never forwarded.

- Write set (5): version.delete, version.upload, version.upload_snapshot, website.deploy, website.undeploy. Shared AccessControlGuard write verbs already classify delete; deploy/undeploy/upload/upload_snapshot are mutating POSTs and need write classification (upload verbs precedent from media_sets / connectivity).

- No binary downloads. No ResourceIterator for delete/get/upload. include_attribution=False (namespace is outside FR-ATTR-4 scope).
- HTTP verbs: POST reads none; deploy/undeploy/upload/upload_snapshot are POST mutating writes.
