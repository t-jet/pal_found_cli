## Technical Scope Defined

### Deliverables

1. **Skill Package Structure**:
   - `SKILL.md` with frontmatter and tool documentation for all 67 operations
   - `scripts/foundry_ontologies_cli.py` (main CLI entry point)
   - `scripts/_foundry_cli_common.py` (copy of shared module from DEV-STORY-002)

2. **CLI Implementation Requirements**:
   - Argparse-based CLI with 19 resource subparsers (action, action_type, attachment, etc.)
   - Integration with `_foundry_cli_common` modules: ConfigLoader, AuthProvider, AsyncClientFactory, AccessControlGuard, RetryHandler, OutputFormatter, ErrorSerializer
   - TOON format support for list operations per ADR-004 algorithm
   - Attribution injection for `query.*` operations per FR-ATTR-4
   - Exit code taxonomy per ADR-001
   - Structured logging per ADR-005

3. **Special Considerations**:
   - **TOON Format**: List operations (`*.list`, `*.list_*`, `*.search`) must implement ADR-004 auto-selection algorithm — use TOON when result is uniform array of dicts, JSON otherwise
   - **Attribution**: `query.execute` requires attribution metadata injection per SRS FR-ATTR-4
   - **Access Control**: All 67 operations subject to AccessControlGuard 8-step precedence check
   - **Async Operations**: Several streaming operations (stream_points, stream_values, stream_geotemporal_series_historic_values) require proper async handling

- Aligns with SAD-001 implementation roadmap definition
- Similar to DEV-STORY-009 (foundry-admin: 66 operations) which is also a single story
