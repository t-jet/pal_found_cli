Decision: rejected. Move to Correction.

Findings:
1. Critical: packaged console entry point can fail outside the repo for wrappers that load implementation from an unpackaged .claude tree. pyproject.toml:26-28 registers console scripts from src package. src/foundry_cli/datasets/scripts/foundry_datasets_cli.py:13-20 builds _LEGACY_SCRIPT as Path(__file__).resolve().parents[4] / ".claude" / "skills" / "foundry-datasets" / "scripts" / "foundry_datasets_cli.py". In an installed wheel, that .claude path is not packaged with the src module, so _load_legacy_cli raises ImportError at src/foundry_cli/datasets/scripts/foundry_datasets_cli.py:26-27. This pattern is a release blocker; do not ship console scripts that depend on workspace-only skill paths.
2. High: pagination dispatch is not compatible with SDK iterator/list operations. src/foundry_cli/common/pagination_helper.py:182 always does response = await call_func(**params). That only works for coroutine-returning methods. Foundry SDK paginated APIs commonly return iterator/page objects, so awaiting a non-awaitable iterator fails before _extract_items can run. src/foundry_cli/ontologies/scripts/foundry_ontologies_cli.py:394-400 routes paginated ontology operations through helper.paginate, so list/search/query paths inherit the bad await behavior.
3. High: attachment upload validates missing filename, but generic exception handling maps it to server error. src/foundry_cli/ontologies/scripts/foundry_ontologies_cli.py:350-351 raises ValueError("filename is required for attachment upload operations"). main catches generic Exception at src/foundry_cli/ontologies/scripts/foundry_ontologies_cli.py:490-492 and returns EXIT_SERVER_ERROR. Missing filename is user input and should return EXIT_USER_INPUT with a clear message.
4. Medium: lint gate is inconsistent. src/foundry_cli/ontologies/scripts/foundry_ontologies_cli.py:2 suppresses E402 for the whole file after path mutation at lines 17-30. The reported ruff check must either scope ignores in pyproject.toml or restructure imports. Also verify stale unused imports such as inspect and EXIT_CONFIGURATION in touched entry point files; current src/tests pass, but repo-wide ruff fails because generated/tracker/.claude paths are included.
