## Business design plan - BA-DES-004 (author ba)

### Business case
One combined repository cannot serve three assets with independent release cadences and contributor bases. Splitting into pal_found_cli (design/docs/tracking), pal_found_cli_tool (CLI source) and pal_found_cli_skills (agent skills) makes per-asset hosting (FEATURE-002), distribution (FEATURE-004/005/007) and maintenance practical.

### Acceptance criteria (scope for design)
- Given the split project, when a user browses any of the three repositories, then each contains only its own content type.
- Given the CLI tool repository, when a user searches for CLI source, then it is present there.
- Given the agent skills repository, when a user searches for skill content, then it is present there.
- Given the design repository, when a user searches for requirements and design documentation, then it is present there.
- Given a cross-repository reference, when a user follows it, then it resolves to the correct location.
- Given the split repositories, when history is verified, then required history is preserved.
