Subject: Safe iterator boundary correction
Created: 2026-10-13T23:35:57
Updated: 2026-10-13T23:35:57
---
Removed the item-count fallback from Ontology _iterator_page. Without SDK raw one-page response or _page_iterator, it raises PaginationBoundaryError (exit 6) before emitting a continuation cursor, preventing skipped oversized-page records. Added a regression test for an iterator without a page boundary. Independent QA verified the failing shape and existing SDK page iterator behavior (comment 20261013-233439-@qa-engineer).
