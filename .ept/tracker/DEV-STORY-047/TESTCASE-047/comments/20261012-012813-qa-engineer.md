### Test cases (Given/When/Then)
**TC-047-01 inventory one-to-one (AC-D-013-08).** Given the 39 frozen action and rich-property keys, when record headings are enumerated in references/03-actions-rich-properties.md and the per-resource files, then every key has exactly one record and no extra or duplicate record exists.
**TC-047-02 record completeness sample (AC-D-013-02..05).** Given action.apply, attachment.upload, cipher_text_property.decrypt, geotemporal_series_property.get_geotemporal_series_latest_value, media_reference_property.get_media_content, ontology_interface.list_objects_for_interface, ontology_object_set.load, ontology_transaction.post_edits, query.execute and time_series_property_v2.stream_points, when each is read, then resource, effect and side effect, input meaning, result and failure interpretation and a coherent example are correct against the installed CLI.
**TC-047-03 offline copied-folder representative run (AC-D-013-06,07).** Given the copied folder with no network, when a novice agent follows one example per client with mock or recorded output, then it chooses valid inputs, interprets the result and next operation, and every required local link resolves.
**TC-047-04 install prerequisite (BR-012-09).** Given pal-found-ontologies/SKILL.md, when the install block is read, then it names pal_found_cli and gives conda `-c t-jet`, pip and uv commands.
**TC-047-05 300-line leaf limit (SA-DES-012).** Given every markdown part, when line counts are checked, then each part is at most 300 lines.
**TC-047-06 action and edit semantics (AC-D-013-03,05,09).** Given action.apply, action.apply_batch, action.apply_with_overrides and ontology_transaction.post_edits, when the records are read, then the effect on ontology objects, the batch and override inputs, and how a pending or unknown edit outcome is distinguished from a committed one are stated.
**TC-047-07 binary and rich-property semantics (AC-D-013-03,04,09).** Given attachment.upload, attachment.read, media_reference_property.upload, media_reference_property.get_media_content, cipher_text_property.decrypt, the time-series streaming operations and ontology_object_set.load, when the records are read, then the bounded binary transfer limits, the streaming nature of time-series reads, the decryption input meaning and the object-set load semantics are stated.
**TC-047-NEG-01 missing or duplicate record.** Given a key with no heading or two headings, when the inventory check runs, then it fails naming the key.
**TC-047-NEG-02 unsupported call.** Given an operation not in the register, when the skill is read, then it is not presented as callable.
**TC-047-NEG-03 stale example.** Given an example selecting a different resource.operation than its heading, when parsed, then it fails.
**TC-047-NEG-04 unresolved link.** Given a relative link that escapes the folder or targets a missing file, when resolved, then it fails.
