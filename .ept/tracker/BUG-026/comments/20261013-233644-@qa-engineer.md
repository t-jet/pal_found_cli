## Scope and preconditions
Independent regression for Ontology, Admin, and Filesystem paginated main collectors in current dirty tool worktree, using local SDK-shaped mocks and RetryHandler. No live Foundry call.

## Given/When/Then scenarios
For each namespace: Given first page returns one item and cursor p2; When page two raises one transient TimeoutError and whole batch retries successfully; Then stdout has exactly two items once, ADR-005 stderr metadata has pages_fetched=2 and total_items=2, next_page_token is final cursor, and mock calls show a fresh attempt.

## Edge and negative cases
Page one followed by terminal empty page: verify two completed pages and one item. Persistent timeout: verify bounded failure and no success metadata. No duplicate items after retry.

## Expected output and test data
Use item IDs 1 and 2, page token p2, mocked page-two TimeoutError once. Assert JSON output and process exit 0 on recovered case; use project timeout defaults for RetryHandler. Capture actual command and outputs. Need Tech Lead approval before extension execution.
