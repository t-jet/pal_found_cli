## Business design plan - BA-DES-005 (author ba)

### Business case
Users and agent harnesses need a standard pip install path for the CLI tool. Publishing the package (package name pal_found_cli per ND-010-02) to PyPI lets any user run pip install without building from source; it is the primary installation channel for Python users and the simplest path for agent harnesses provisioning tools.

### Acceptance criteria (scope for design)
- Given a user with Python and pip, when they run pip install on the published package, then the tool installs successfully.
- Given an installed release, when the user runs the tool command, then it works as documented.
- Given a published new version, when a user runs a pip upgrade, then they receive the new version.
- Given a release candidate, when it is published, then the maintainer verifies a clean install before marking it stable.
- Given the package page, when a user opens it, then it explains what the tool does and how to install and use it.
- Given a published artifact, when it is scanned, then it contains no embedded credentials.
