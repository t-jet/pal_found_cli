## Business design plan - BA-DES-006 (author ba)

### Business case
Conda-based environments do not use pip. Publishing the tool (package name pal_found_cli per ND-010-02) to a conda channel lets conda users install with one command, complementing the PyPI channel (FEATURE-004) and widening reach across Python environments.

### Acceptance criteria (scope for design)
- Given a user with conda, when they install the package from the configured channel, then the tool installs successfully.
- Given an installed release, when the user runs the tool command, then it works as documented.
- Given a published new version, when a user updates the package via conda, then they receive the new version.
- Given a user without channel access, when they try to install, then the attempt fails with a clear message.
- Given the channel page, when a user opens it, then it explains what the tool does and how to install it.
- Given conda and PyPI releases, when versions are compared, then they are published from the same versioned source.
