### Blocker 3 (Minor): DEV-STORY-001 — OAuth2 Inconsistency
DEV-STORY-001 description states: "AuthProvider: Handle OAuth2 token acquisition and validation"

However, SRS-001 Section 1.2 (Scope) explicitly lists OAuth2 as OUT OF SCOPE:
- FR-AUTH-3: OAuth2 authentication (ConfidentialClientAuth, PublicClientAuth) SHALL NOT be implemented.
- Section 2.5 Design Constraints: OAuth2/OIDC authentication flows excluded.

The AuthProvider should only handle UserTokenAuth (FOUNDRY_TOKEN from environment). This is a documentation inconsistency that should be corrected.
