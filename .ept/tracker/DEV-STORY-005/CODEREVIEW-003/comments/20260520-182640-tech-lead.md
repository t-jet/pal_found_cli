#### CRITICAL: _invoke_async Missing Required timeout Parameter

**File**: `foundry_datasets_cli.py`, line ~420

The timeout parameter is missing from the lambda call to _invoke. This will cause a TypeError at runtime on every operation invocation.

Additionally: _invoke is declared as async def but is being wrapped in run_in_executor which runs it in a thread pool executor. This defeats the async pattern.

#### WARNING: RetryHandler Imported But Never Used

**File**: `foundry_datasets_cli.py`, line ~45

RetryHandler is imported from foundry_cli.common.retry but never instantiated or applied to any operation. Per ADR-002, all API calls should use exponential backoff with jitter retry logic.

#### WARNING: timeout Not Resolved From Config

**File**: `foundry_datasets_cli.py`, line ~353

The timeout parameter is never extracted from args or cfg before being passed to _invoke_async.

#### WARNING: METADATA_SEPARATOR Imported But Unused
