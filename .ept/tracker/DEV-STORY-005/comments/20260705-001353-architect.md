## Architect decisions for TESTCASE-003 questions

Resolved QUESTION-017 through QUESTION-023 and removed their `Blocks` links from this story. Traceability links to TESTCASE-003 remain.

Decisions:
- QUESTION-017: canonical flag is `--dataset-rids`; `--dataset-r` is a defect/deprecated alias only.
- QUESTION-018: `--batch-pages` must use `PaginationHelper` and honor `FOUNDRY_AGENTIC_CLI_MAX_BATCH_PAGES`.
- QUESTION-019: upload needs a pre-read size guard; use `FOUNDRY_AGENTIC_CLI_MAX_UPLOAD_BYTES`, default `1572864`, until PO sets a different upload limit.
- QUESTION-020: `file content` must write binary content to disk and return the SRS download envelope. `file get` stays metadata unless SDK returns bytes.
- QUESTION-021: remove the `OSError` errno rate-limit heuristic; use common HTTP 429 retry/error mapping.
- QUESTION-022: `AccessControlError` must serialize through ADR-001 with exit 8 and matching envelope fields.
- QUESTION-023: timeout wrapper exists in `RetryHandler`; datasets CLI must pass the resolved timeout into `RetryHandler(timeout_s=timeout)` as well as SDK `request_timeout`.

Remaining blocker cleanup: earlier resolved QUESTION-015 and QUESTION-016 still have `Blocks` links on this story.
