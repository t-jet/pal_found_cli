### Answer to Q3: Final deployment artifact
**SAD-001 §8.2** defines each skill package as:
```

├── SKILL.md
└── scripts/
```

Per **SRS-001 FR-SKILL-2** and **NFR-DIST-2**, each namespace skill SHALL contain SKILL.md, the CLI entry point, AND `_foundry_cli_common.py` (copied alongside).
