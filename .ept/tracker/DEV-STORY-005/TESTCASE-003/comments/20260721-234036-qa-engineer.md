# Title / ID naming convention note

The ticket `id` is **TESTCASE-003** but the `title` text begins with **"TESTCASE-005:"**.
This was flagged during the in-progress DoD audit and is **intentional, not a defect**.

## Why

This project uses a sub-task numbering convention where the textual descriptor in the
title carries the **parent DEV-STORY suffix**, while the ticket `id` reflects the
ticket's actual creation index in the tracker. All DEV-STORY-005 sub-tasks follow this
pattern:

| id | title |
|---|---|
| DESIGN-003 | DESIGN-005: Technical design for foundry-datasets skill |
| DEV-003 | DEV-005: Implement foundry-datasets skill (26 operations) |
| CODEREVIEW-003 | CODEREVIEW-005: Code review for foundry-datasets implementation |
| UNITTEST-003 | UNITTEST-005: Unit tests for foundry-datasets |
| TESTCASE-003 | TESTCASE-005: QA test cases for foundry-datasets |
| TESTEXEC-003 | TESTEXEC-005: Execute QA tests for foundry-datasets |
| DEVOPS-004 | DEVOPS-005: Deploy foundry-datasets skill |

The "005" descriptor matches the parent DEV-STORY-005 number (grouping); the per-type
counter ("-003"/"-004") is the actual tracker ID. Recorder (architect) confirmed this
convention by adopting it consistently across all sub-tasks of DEV-STORY-005.

## Action

No title change. Documented here so future readers do not re-flag this as a defect.
