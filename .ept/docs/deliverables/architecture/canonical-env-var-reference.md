## Overview


This document is the authoritative mapping of every SDK path to its corresponding
environment variable name. Review and update on every `foundry-platform-python` minor release.


**Naming conventions:**

| Scope | Pattern | Example |
|---|---|---|
| Global | `FOUNDRY_AGENTIC_CLI_{KEY}` | `FOUNDRY_AGENTIC_CLI_READONLY` |
| Namespace | `FOUNDRY_AGENTIC_CLI_{NS}_{CONTROL}` | `FOUNDRY_AGENTIC_CLI_DATASETS_READONLY` |
| Operation | `FOUNDRY_AGENTIC_CLI_{NS}_{CLASS}_{OP}_{CONTROL}` | `FOUNDRY_AGENTIC_CLI_DATASETS_DATASET_GET_ENABLED` |

**Control suffixes:**

| Suffix | Values | Applies to |
|---|---|---|
| `_ENABLED` | `true` (default) / `false` | Namespace, Operation |
| `_READONLY` | `false` (default) / `true` (override only) | Namespace-level (set) or operation-level (override only per ADR-007) |
| `_METADATA_ONLY` | `false` (default) / `true` | Namespace-level only |
