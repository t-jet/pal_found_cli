# CLI utility for access Foundry API via command-line tools

## Goal
This project aims to implement set of CLI tools which will allow AI agents to access Palantir Foundry API.



## Requirements

### FR-01 Implementation scope

Tools should cover all capabilities provided by SDK.

### FR-02 Implementation scope


### NFR-01

Tools should be implemented using Python 3.11.*

### NFR-02

Tools should leverage Palantir Foundry API Python SDK.
SDK source provided in the `.ept/docs/customer_input/foundry-platform-python` folder.
Web site with documentation located [here](https://www.palantir.com/docs/foundry/api/v2).


### NFR-03

Toolset should be implemented as a Claude agent skill which can be used by agents.
